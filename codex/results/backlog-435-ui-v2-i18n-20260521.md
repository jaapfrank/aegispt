# backlog-435 — ui-v2 internationalization validation

## Scope

Implemented static, repo-backed internationalization for `ui-v2` with supported locales:

- `en`
- `nl`
- `de`
- `fr`

English remains the default and fallback. The language selector is visible in the top bar and persists the selected locale in `localStorage`.

## Implemented Surfaces

- Shell navigation and section labels
- New Mission entrypoint and Intake heading
- Command palette shell copy
- Settings title, tabs, summary chips, refresh/save controls, and ChatGPT OAuth entrypoint labels
- Mission Control empty-state entrypoint and V3 Story/Technical switcher labels
- Static locale parity script and Playwright i18n browser coverage

## Validation

- `cd ui-v2 && npm run lint` passed.
- `cd ui-v2 && npm run build` passed.
- `cd ui-v2 && npm run test -- --run i18n` passed:

  - desktop browser: Nederlands -> Settings persistence -> Deutsch -> Mission Control -> Francais
  - mobile browser: Francais selector and translated navigation/settings
