# UI Future Requirements

## Purpose

This document records forward UI requirements without implementing them in Prompt 3.

## Future views

- attack path visualization
- identity graph
- risk scoring display
- trend view
- comparison between runs

## Data sources

These future views should build on:

- existing findings and provenance
- runtime pack binding
- future attack path engine
- future identity model
- future risk scoring
- future customer memory and continuous mode layers

## Constraint

Future UI work must keep the operator experience clear and must not hide validation, approval, or deployment state behind opaque automation.
