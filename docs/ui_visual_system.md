# UI Visual System

## Direction

The operator UI uses a dark premium command-center style with restrained cyan and amber accents. The visual system should feel cinematic without becoming decorative noise.

## Core palette

- deep navy / near-black surfaces
- cyan for active flow and live motion
- amber for guarded action and advisory emphasis
- green for healthy or completed state
- red for blocked, failed, or critical state
- muted steel-blue for unknown or low-confidence state

## Typography

- condensed display feel for headings
- clean, readable body typography
- uppercase eyebrow labels for navigation and section framing

## Motion

Allowed:

- phase progress glow
- active node pulse
- subtle connection flow
- screen fade transitions

Avoid:

- decorative particle systems
- noisy looping effects
- motion that obscures status or data

## State language

- healthy: green
- active: cyan
- warning / waiting: amber
- blocked / failed: red
- unknown / reserved future overlay: muted blue
