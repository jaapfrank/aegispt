# Continuous Mode

## Purpose

This document prepares for future recurring assessments without implementing scheduling now.

## Future capabilities

- recurring runs
- delta comparison between runs
- drift detection
- trend tracking
- repeated adaptive pack refresh cycles

## Data reuse

Continuous mode should reuse:

- engagements
- runs
- findings
- pack provenance
- future customer memory

## Non-goal

Prompt 3 does not introduce:

- a scheduler
- background recurring jobs
- automatic runtime mutation
