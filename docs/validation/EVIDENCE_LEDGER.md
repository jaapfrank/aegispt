# EVIDENCE LEDGER — the single source of truth for solve/finding status

**This file (+ `evidence_ledger.jsonl`) is THE canonical record.** No other doc may claim a
different solve-count. If a number appears elsewhere, it must link here. (Rework-4, plan
`docs/strategy/rework4-execution-plan-2026-06-08.md`, task 0.3.)

Rule: a row is `solved`/`admin`/`finding` ONLY if an exploit attempt produced **evidence**
(admin reached, secret/flag read, marker reflected) — "No Exploit, No Report".

## Schema (`evidence_ledger.jsonl`)

One JSON object per canonical target status, plus optional held-out transfer
eval rows. Historical run artifacts are deduplicated to one current row per
XBEN target; live run facts are represented through `run_id`, `brain`,
`evidence_ref`, and `proof_status`. Held-out transfer rows are canonical eval
evidence for model/training comparison, but they do not change the XBOW
target score denominator.

| field | meaning |
|---|---|
| `schema_version` | `aegispt.evidence-ledger.v1` |
| `row_id` | deterministic row hash |
| `row_type` | `target_status` \| `heldout_transfer_eval` |
| `ts` | ISO timestamp |
| `benchmark` | benchmark family, e.g. `XBOW` |
| `target` | XBEN id with suffix, e.g. `XBEN-024-24`, URL for future non-XBEN rows, or held-out `scenario_id` |
| `xben_id` | normalized XBEN id without suffix |
| `brain` | provider/model driving the loop (e.g. `chatgpt_oauth`, `local-qwen`) |
| `outcome` | `solved` \| `admin` \| `finding` \| `attempted_no_solve` \| `no_finding` \| `infra_blocked` \| `scaffold_error` \| `unknown` \| `known_clean` \| `known_vulnerable` \| `live_no_oracle` |
| `evidence_ref` | artifact path proving the status; flag literals are hashed, not copied |
| `evidence_level` | artifact class, e.g. `flag_capture_persisted_finding`, `readme_byte_equal_solve`, `matrix_status` |
| `proof_status` | proof detail, e.g. `flag_capture_persisted`, `grader_solved_not_finding_persisted`, `attempted_no_solve` |
| `reportability_class` | derived No-Exploit-No-Report class: `exploit_proven` \| `passive_observation` \| `unproven` |
| `reportable_under_no_exploit_no_report` | derived boolean; only `true` rows count as exploit-proven under the shared taxonomy |
| `run_id` | engagement run id |
| `flag_sha256` | SHA-256 of benchmark flag when present; empty otherwise |
| `source_status` | original imported status from the source matrix |
| `status_source` | source family used for the row, e.g. validation artifact or gap matrix |
| `review_flags` | reconciliation warnings requiring human review |
| `notes` | short |
